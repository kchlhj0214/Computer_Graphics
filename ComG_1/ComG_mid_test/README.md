# 중간고사 탱크 조립 코드 사용 안내

## 1. 수정할 파일과 순서

`ComG_mid_test.cpp`의 **1번 설정값**, **2번 파트/ID**, **3번 BuildTank()**를 주로 수정합니다.

| 파일 | 역할 |
|---|---|
| `ComG_mid_test.cpp` | 설정, 탱크 조립 예제, 카메라, 입력, 그리기 |
| `TankScene.h` | 도형 클래스, 연결, 신축·회전·이동 기능 |
| `ShapeMeshes.h` | 다섯 종류 도형의 삼각형 정점 생성 |
| `vertex.glsl`, `fragment.glsl` | 모든 도형이 공유하는 변환·색상 셰이더 |
| `SceneTests.cpp`, `SceneTests.vcxproj` | 연결·동작·렌더링 검증용 별도 프로젝트 |

`BuildTank()`에서는 다음 순서를 지킵니다.

1. `scene.Add(...)`로 도형을 모두 등록합니다.
2. `scene.Attach(...)` 또는 `scene.AttachOnTop(...)`으로 연결합니다.
3. `scene.AddScale(...)`, `scene.AddRotation(...)` 등의 기능을 등록합니다.
4. 마지막에 `scene.Seal()`을 한 번 호출합니다.

설정 변경 후 다시 빌드하고 실행합니다. 실행 중 도형을 편집하는 프로그램은 아닙니다.

## 2. 도형 만들기

```cpp
scene.Add(Box(
    60,                         // 중복되지 않는 도형 ID
    BODY,                       // 소속 파트
    {0.0f, 0.0f, 0.0f},        // 위치: 연결 여부에 따라 의미가 달라집니다.
    {0.4f, 0.2f, 0.3f},        // 전체 폭 X, 높이 Y, 깊이 Z
    Color::Fixed(0.9f, 0.1f, 0.1f)
));
```

`Box` 대신 `Cone`, `Cylinder`, `Sphere`, `Pyramid`를 사용하면 각각 원뿔, 원기둥, 구, 사각뿔이 됩니다. 생성 인자는 모두 같습니다.

- ID는 식별 번호입니다. 큰 번호라고 위에 배치되는 것은 아닙니다.
- 파트는 여러 도형을 묶는 번호입니다. `TankPart`에 새 항목을 추가해도 됩니다.
- 원뿔·원기둥·사각뿔은 기본적으로 Y축이 높이 방향입니다.
- 구의 크기는 반지름이 아니라 지름입니다. 축별 크기를 다르게 주면 타원체가 됩니다.
- 앞은 -Z, 뒤는 +Z입니다.
- 크기는 모두 양수여야 합니다.

초기 회전은 도형 등록 후, 연결과 `Seal()` 전에 설정합니다.

```cpp
scene.Get(60).angles = {0.0f, 0.0f, 90.0f};
```

각도 단위는 도이며 GLM의 Euler → quaternion 변환을 사용합니다. `angles`는 초기 자세이고, 키보드 회전은 그 자세에 추가됩니다.

### 위치의 의미

- 연결하지 않은 도형: 탱크 원점 기준 중심 위치입니다.
- `Attach`한 도형: 두 접점을 맞춘 상태에서 추가할 위치입니다. 기본값 `{0,0,0}`이면 접점이 일치합니다.
- `AttachOnTop`한 도형: 지지 도형들의 중심 평균 XZ와 최고 높이를 기준으로 한 추가 위치입니다.

독립된 높이 0.2 도형을 바닥 위에 놓으려면 중심 Y를 0.1로 설정합니다. 연결한 도형에는 부모 높이를 직접 더하지 않습니다.

### 색상

```cpp
Color::Fixed(0.9f, 0.1f, 0.1f)   // 시작 색상 지정
Color::Random()                  // 이 도형만 독립 추첨
Color::Random(WHEELS)            // 같은 색상 그룹끼리 같은 랜덤색
```

색상 그룹과 동작 파트는 별개입니다. 같은 숫자를 사용하면 설정하기 편할 뿐, 반드시 같을 필요는 없습니다.

`o`는 고정색으로 시작한 도형도 다시 추첨합니다. `c`는 프로그램 시작 시 저장한 색상으로 복구합니다. 랜덤 RGB 범위는 `COLOR_MIN`, `COLOR_MAX`입니다.

## 3. 부품 연결: 이동·회전 상속과 독립 동작

```cpp
scene.Attach(
    TURRET_LEFT,                // 자식 ID
    BODY_MAIN,                  // 부모 ID
    Shape::bottom,              // 자식의 접점
    Shape::top,                 // 부모의 접점
    {0, 0, 0},                  // 추가 간격
    true                        // 부모 회전 상속
);
```

기준점은 `Shape::center`, `left`, `right`, `bottom`, `top`, `front`, `back`을 사용합니다. `scene.Get(60).bottom`처럼 객체를 통해 접근해도 됩니다. 기준점은 도형의 로컬 바운딩 박스 면 중심입니다. 원뿔의 `top`은 꼭짓점이며, 모든 모양의 접점이 넓은 평면이라는 뜻은 아닙니다.

### 부모 신축과 자식 크기

부모의 신축은 접점 위치에 반영되지만 자식의 크기에 곱해지지 않습니다. 몸통 높이를 키우면 위 부품의 위치가 올라가고, 위 부품 자체의 크기는 유지됩니다.

부모의 이동·회전은 자식에게 전달됩니다. 부모의 크기 변화까지 자식 크기에 전달하는 옵션은 현재 제공하지 않습니다. 자식도 신축하려면 자식에게 별도 신축 기능을 등록합니다.

회전 상속을 `false`로 지정하면 부모의 접점 위치는 따라가지만 자식의 방향은 부모 회전을 따라가지 않습니다. 접점이 부모 중심 밖에 있다면 부모 회전 때문에 접점 위치 자체는 움직일 수 있습니다.

### 포신처럼 붙어 있으면서 혼자 회전하기

```cpp
scene.Attach(GUN_LEFT, TURRET_LEFT, Shape::back, Shape::center);
scene.AddRotation(
    Id(GUN_LEFT), GLFW_KEY_G, {0, 1, 0}, Shape::back,
    1, BARREL_ROTATE_SPEED, 180, Mode::Once
);
```

포신 뒤쪽을 상부 몸체 중심에 연결하고 같은 뒤쪽 접점을 회전 기준으로 사용합니다. 중앙 몸체와 상부 몸체의 이동·회전은 따라가면서, `g`를 누르면 포신만 추가로 회전합니다.

연결 접점과 회전 기준점이 다르면 회전 중 연결 접점이 이동할 수 있습니다. 연결을 고정하려면 두 기준점을 같게 설정합니다.

### 바퀴 두 개 위에 몸통 올리기

```cpp
scene.AttachOnTop(BODY_MAIN, Part(WHEELS));
```

바퀴 파트 도형들의 XZ 중심 평균 위에 몸통을 놓습니다. 높이는 가장 높은 월드 바운딩 박스 윗면을 사용합니다. 바퀴 높이가 달라도 몸통은 수평을 유지합니다. 이 연결은 개별 바퀴의 회전을 몸통에 전달하지 않습니다.

회전된 구·원뿔 등은 실제 표면보다 바운딩 박스가 넓을 수 있습니다. 정밀한 표면 접촉이나 물리 충돌을 계산하는 기능은 아닙니다.

## 4. 파트 동작과 개별 동작

```cpp
Id(WHEEL_LEFT)   // 한 도형만 선택
Part(WHEELS)    // 바퀴 파트 전체 선택
```

바퀴 높이를 항상 같게 유지하려면 초기 높이도 같게 설정하고, **파트 신축 기능 하나**를 등록합니다. 한 기능의 배율을 공유하므로 진행 시간이 서로 어긋나지 않습니다.

```cpp
scene.AddScale(
    Part(WHEELS), GLFW_KEY_D,
    {0, 1, 0}, Shape::bottom,
    0.5f, 1.5f, 0.6f, Mode::PingPong
);
```

개별 바퀴를 따로 움직이려면 파트 기능 대신 각 ID에 별도 키를 등록합니다. 같은 ID에 파트 신축과 개별 신축을 중복 등록하면 `Seal()`이 오류를 알립니다.

부모와 그 자식을 같은 이동 파트에 넣으면 자식은 부모를 따라가는 이동에 자신의 이동까지 더합니다. 전체 구조를 한 번 움직이고 싶다면 부모에만 기능을 부여합니다.

## 5. 기능별 인자

### 신축

```cpp
scene.AddScale(대상, 키, 축마스크, 기준점, 최소배율, 최대배율, 초당배율, 모드);
```

- `{0,1,0}`: Y축만, `{1,1,1}`: 모든 축을 같은 배율로 신축합니다.
- 배율은 초기 크기에 곱합니다. 1.5이면 초기 크기의 1.5배입니다.
- 최소 > 0, 최소 ≤ 1 ≤ 최대, 최소 < 최대여야 합니다.
- `bottom`이면 아래쪽을 유지하고 위로 늘어납니다. `center`이면 양쪽으로 늘어납니다.
- 속도 0.6은 1초에 배율이 0.6 변한다는 뜻입니다.

### 회전

```cpp
scene.AddRotation(대상, 키, 축, 기준점, 방향, 초당각도, 사이클각도, 모드);
```

- `{0,1,0}`은 도형의 초기 자세 기준 Y축입니다.
- 방향은 +1 또는 -1입니다. 양의 회전은 OpenGL 오른손 법칙을 따릅니다.
- 90도/초, 180도 한 사이클이면 2초 동안 회전합니다.
- `Once`를 다시 실행하면 현재 각도에서 한 사이클을 더 회전합니다.

기존 예제의 포신은 다음 추가 설정으로 매번 바깥쪽을 선택합니다.

```cpp
scene.SetOutwardRotation(회전기능번호, 상부몸체ID);
```

이 옵션은 기존 탱크처럼 앞이 -Z이고 상부 몸체가 좌우 X축에 배치된 **Y축·180도·Once** 회전용입니다. 일반 회전 설정으로 변경하려면 해당 `SetOutwardRotation` 호출을 제거하고 방향을 직접 정합니다. 위치 교환 도중 회전을 시작하면 키를 누른 순간의 좌우 위치로 방향을 결정합니다.

### 이동

```cpp
scene.AddMovement(대상, 키, 방향, 사이클거리, 초당거리, 모드);
```

방향은 부모 좌표계 기준이며 자동 정규화합니다. 부모가 없으면 월드 축 기준입니다. 여러 이동 기능은 합산할 수 있습니다.

```cpp
// 상부 파트가 X방향으로 0.2 이동했다가 돌아오는 동작
scene.AddMovement(Part(TURRETS), GLFW_KEY_U, {1,0,0}, 0.2f, 0.1f, Mode::PingPong);
```

### 위치 교환

```cpp
scene.AddSwap(TURRET_LEFT, TURRET_RIGHT, GLFW_KEY_L, 1.0f);
```

1초 동안 서로 겹쳐 지나가며 교환합니다. 다음 입력은 반대로 교환합니다. 두 도형은 부모, 연결 접점, 연결 간격이 같아야 합니다. 연결된 자식들도 따라갑니다. 현재 기능은 같은 크기의 상부 몸체를 교환하는 기존 예제에 맞는 위치 교환이며, 서로 다른 크기의 도형 표면을 충돌 없이 재배치하는 기능은 아닙니다.

### 반복 방식

| 모드 | 회전·이동 | 신축 | 키 재입력 |
|---|---|---|---|
| `Once` | 현재 상태에서 한 사이클 후 종료 | 현재 배율에서 최대까지 확대 후 종료 | 동작 중 무시 |
| `Loop` | 같은 방향으로 계속 진행 | 최대에 도달하면 최소로 돌아가 반복 | 현재 상태에서 정지·재개 |
| `PingPong` | 시작 상태와 지정 거리/각도 사이 왕복 | 최소와 최대 사이 왕복 | 현재 상태에서 정지·재개 |

`Loop` 이동·회전은 사이클 경계에서 위치/각도를 초기화하지 않습니다. 신축 `Once`는 최대 도달 후 다시 눌러도 더 커지지 않습니다. 초기 배율로 돌아가려면 `c` 또는 왕복 모드를 사용합니다.

## 6. 새 부품을 추가하는 예제

아래 코드는 `BuildTank()`에서 **기존 마지막 `scene.Seal()` 바로 앞**에 넣습니다. 기존 키와 겹치지 않는 `u`를 사용합니다.

```cpp
// 예시 값도 자주 바꿀 계획이면 위쪽 #define으로 옮깁니다.
scene.Add(Cone(
    60, BODY, {0,0,0}, {0.15f,0.20f,0.15f},
    Color::Fixed(0.9f,0.7f,0.1f)
));
scene.Attach(60, TURRET_LEFT, Shape::bottom, Shape::top);
scene.AddScale(Id(60), GLFW_KEY_U, {0,1,0}, Shape::bottom,
    0.5f,1.5f,0.4f,Mode::PingPong);
```

상부 몸체 위에 원뿔이 생기고 `u`로 신축합니다. `t`의 중앙 회전과 `l`의 상부 교환도 자동으로 따라갑니다. 위 부품을 더 추가하려면 이 원뿔 ID 60을 부모로 연결합니다.

현재 예제에서 `BODY` 파트 전체를 대상으로 하는 기능은 없으므로 위 예제가 독립적으로 동작합니다. 이후 `Part(BODY)` 신축을 추가하면 ID 60의 신축과 겹치므로 둘 중 하나만 등록합니다.

## 7. 현재 제한과 설정 오류

- 도형 하나당 회전 기능 하나, 신축 기능 하나를 지원합니다. 서로 다른 도형끼리는 동시에 실행할 수 있습니다.
- 이동 기능은 여러 개를 합산합니다. 같은 키를 여러 기능에 지정하면 동시에 실행됩니다.
- `x/z/y/r/o/c/q`, 방향키는 카메라·전체 조작에 사용하므로 새 기능은 다른 키를 사용하는 것이 편합니다. 같은 키를 쓰면 두 동작이 모두 실행됩니다.
- 현재 구조는 모든 도형 생성 및 초기 설정을 끝낸 후 `Seal()`을 호출하는 방식입니다. 실행 중 ID, 파트, 크기, 연결을 바꾸는 용도는 아닙니다.
- 순환 연결, 중복 ID, 없는 ID, 빈 파트, 잘못된 속도/크기 등은 콘솔에 오류를 출력하고 종료합니다.
- 바닥 경계는 도형의 바운딩 박스를 기준으로 제한합니다. 탱크 전체가 바닥보다 큰 설정은 오류입니다. 벽 충돌이나 부품끼리의 충돌 계산은 없습니다.
- `KeepOnFloor`는 XZ 경계 제한입니다. 루트 도형을 직접 바닥 아래에 생성하거나 Y축 이동 기능을 부여하는 경우 높이까지 자동 보정하지 않습니다.
- 부모 크기를 자식 크기에 곱하지 않으므로 상위 몸체를 크게 해도 자식은 그대로입니다. 연결 높이만 바뀝니다.
- 일반 위치·회전·신축과 도형 종류 변경에는 셰이더 수정이 필요 없습니다. 조명/텍스처를 추가할 때는 정점 정보와 셰이더를 확장해야 합니다.

## 8. 현재 키와 검증

| 키 | 동작 |
|---|---|
| 방향키 | 탱크 XZ 이동, 대각선 지원 |
| `d` | 바퀴 파트 높이 왕복·정지 |
| `t` | 중앙 몸체와 연결된 상부 전체 180도 회전 |
| `g` | 포신 각각 바깥쪽 180도 회전 |
| `p` | 깃대 각각 반대 방향 360도 회전 |
| `l` | 상부 몸체 위치 교환 |
| `x/X`, `z/Z` | 카메라 월드 +X/-X, +Z/-Z 이동 (대문자는 Shift) |
| `y/Y` | 카메라 자신의 위쪽 축 기준 자전 토글 |
