# 중간고사 조립 코드 사용 안내

## 1. 어디를 수정하나요?

프로그램 구현은 `ComG_mid_test.cpp` 한 파일에 있습니다. 도형·연결·애니메이션용 별도 헤더는 없습니다. `vertex.glsl`, `fragment.glsl`은 기존처럼 별도 파일입니다.

주로 다음 구역을 수정합니다.

- **1번 설정값:** 창, 카메라, 바닥, 속도 등
- **5번 파트와 도형 ID:** 사용할 파트와 도형 이름
- **6번 BuildTank():** 도형 생성 → 층 배치/부속 연결 → 기능 부여 → `Seal()`

`SceneTests.cpp`와 `SceneTests.vcxproj`는 별도 검증 프로그램입니다. 실제 프로그램 빌드에 포함되지 않습니다.

## 2. ID, 층, 파트를 구별하기

| 구분 | 용도 | 예 |
|---|---|---|
| 도형 ID | 개별 도형 식별, 중복 불가 | `WHEEL_LEFT`, `BODY_MAIN`, `GUN_LEFT` |
| 층 번호 | 아래부터 쌓이는 순서, 여러 도형이 같은 층 사용 가능 | 1층 바퀴, 2층 몸통, 3층 조종석 |
| 파트 | 같은 기능을 적용할 도형 묶음 | `WHEELS`, `BARRELS` |
| 부속 연결 | 특정 도형에 붙은 자식 | 왼쪽 조종석에 붙은 포신 |

`3_1` 같은 부속 관계는 숫자를 소수점으로 표현하지 않습니다. **부모 도형 ID와 부속 도형 ID를 각각 정하고 `Attach`로 연결**합니다. 같은 3층에 조종석이 두 개라면 각 조종석이 자기 포신을 가질 수 있습니다.

## 3. 도형 생성: 크기와 초기 각도

```cpp
scene.Add(Cylinder(
    60,                         // 고유 ID
    BARRELS,                    // 파트
    {0,0,0},                    // 위치/추가 간격
    {.10f,.50f,.10f},            // 초기 로컬 X/Y/Z 전체 크기
    Color::Random(BARRELS),      // 색상
    {25,40,15}                  // 초기 X/Y/Z 회전 각도, 단위: 도
));
```

종류는 `Box`, `Cone`, `Cylinder`, `Sphere`, `Pyramid`이며 생성 인자는 같습니다. 원뿔·원기둥·사각뿔은 회전 전 +Y를 위로 향합니다. 구의 크기는 반지름이 아니라 전체 지름입니다.

마지막 각도 인자를 생략하면 `{0,0,0}`입니다. 임의 각도를 입력할 수 있으며 행렬은 `Rz * Ry * Rx`로 적용됩니다. 각도는 생성 후 `scene.Get(60).angles={25,40,15};`로 설정해도 됩니다. 설정은 `Seal()` 전에 완료합니다.

기본 윗방향 +Y를 여섯 방향으로 돌리는 값은 다음과 같습니다. 별도 방향 enum 없이 각도 값을 사용합니다.

```cpp
// +X: {0,0,-90}    -X: {0,0,90}
// +Y: {0,0,0}      -Y: {180,0,0}
// +Z: {90,0,0}     -Z: {-90,0,0}
```

크기는 회전 전 로컬 축 기준입니다. `{.1f,.5f,.1f}` 원기둥에 `{-90,0,0}`을 지정하면 길이 .5인 축이 -Z를 향합니다.

`Shape::top`은 회전 후에도 도형 자체의 윗끝을 뜻합니다. 월드의 위쪽과 다를 수 있습니다. 기준점은 `center`, `left`, `right`, `bottom`, `top`, `front`(-Z), `back`(+Z)입니다. 곡면 도형에서도 로컬 바운딩 박스의 면 중심을 사용합니다.

### 색상

```cpp
Color::Fixed(.9f,.1f,.1f)     // 시작 RGB 고정
Color::Random()               // 독립 추첨
Color::Random(BARRELS)        // 같은 색상 그룹은 같은 랜덤색
```

`o`는 모든 도형의 색을 그룹별로 다시 추첨하고 `c`는 시작 색으로 복구합니다. RGB 추첨 범위는 `COLOR_MIN`~`COLOR_MAX`입니다. 색상 그룹과 파트는 별개지만 같은 번호를 사용하면 편합니다.

## 4. 층을 쌓는 방법

모든 도형을 생성한 다음 층을 지정합니다.

```cpp
scene.SetLayer(Part(WHEELS), 1);
scene.SetLayer(Id(BODY_MAIN), 2);
scene.SetLayer(Part(TURRETS), 3);
```

- 층 번호는 양수입니다. 같은 층에 도형이 1개·2개·3개 이상 있어도 됩니다.
- 자기보다 낮은 번호 중 **가장 가까운 비어 있지 않은 층** 위에 배치됩니다.
- 아래층이 여러 도형이면 가장 높은 바운딩 박스 윗면을 사용합니다.
- 2층이 없으면 3층은 1층 위로 내려옵니다. 아래층이 전혀 없으면 바닥에서 시작합니다.
- **X·Z는 각 도형의 생성 위치를 유지합니다.** 바퀴 하나를 지워도 평균 위치로 끌려가지 않습니다.
- 생성 위치의 Y는 아래층에서 띄울 추가 높이입니다. 기본은 0으로 둡니다.
- 층 높이에는 그 층의 기본 도형만 포함합니다. 포신·안테나 같은 부속 높이는 포함하지 않습니다.
- 도형을 생략할 때 생성문만 제거해도 빈 파트/없는 ID에 대한 `SetLayer`는 건너뜁니다.

### 높이 연결과 이동·회전 연결은 별개

기본 `SetLayer(대상,층)`은 높이만 연결합니다. 아래층이 옆으로 움직이거나 회전해도 XZ와 방향은 따라가지 않습니다.

기존 탱크처럼 중앙 몸체의 이동·회전을 상부가 따라가게 하려면 선택적으로 참조 ID를 지정합니다.

```cpp
scene.SetLayer(Part(TURRETS), 3, BODY_MAIN);
```

`BODY_MAIN`이 있으면 그 중심을 기준으로 이동·회전을 따릅니다. 몸통을 삭제해도 상부는 사라지지 않고 아래의 남은 층 위에 배치됩니다. 참조 ID는 더 낮은 층의 기본 도형이어야 합니다. 따라서 **층 참조와 부속 부모는 삭제 시 동작이 다릅니다.**

### 접촉 유지와 자유 기준점

```cpp
scene.SetLayer(Id(BODY_MAIN), 2, -1, true);  // 기본: 아래쪽 접촉 유지
scene.SetLayer(Id(BODY_MAIN), 2, -1, false); // 초기 높이만 정렬, 동작 기준점 허용
```

기본값 `true`는 회전·신축 후에도 변환된 바운딩 박스 아래쪽을 아래층 높이에 맞춥니다. 그래서 층 도형은 바닥을 파고들지 않지만, 중심 신축 등에서 Y 위치가 추가로 보정됩니다. 설정한 회전·신축 기준점의 위치를 그대로 유지해야 하면 `false`로 선택합니다. 이 경우 도형이 아래층을 파고들거나 떨어질 수 있습니다.

`Attach`한 부속에는 이 층 접촉 보정을 하지 않습니다. 부속의 개별 기준점은 그대로 작동합니다.

## 5. 각 도형에 부속 달기

```cpp
scene.Attach(
    60,                      // 부속 ID
    TURRET_LEFT,             // 정확한 부모 도형 ID
    Shape::bottom,           // 부속의 접점
    Shape::center,           // 부모의 접점
    {0,0,0},                 // 추가 간격
    true                     // 부모 회전 상속 여부
);
```

위에서 생성한 임의 각도 원기둥의 밑끝이 왼쪽 조종석 중심에 붙습니다. 부모를 `WHEEL_LEFT`나 `BODY_MAIN`으로 바꿔도 같은 방식으로 작동합니다. 부속을 부모로 지정해 손자 부속을 더 붙일 수도 있습니다.

- 부속은 별도 층에 올리지 않습니다. `Attach`하면 해당 도형의 층 지정은 해제됩니다.
- 부모 이동·회전을 따르지만 **부모 신축 배율은 자식 크기에 곱하지 않습니다.** 접점 위치만 따라갑니다.
- 부모 회전을 상속하지 않으려면 마지막 인자를 `false`로 지정합니다. 부모 접점이 회전 때문에 움직이면 접점 위치는 따라갑니다.
- **정확한 부모 ID가 없거나 부모가 숨겨지면 부속과 모든 자손을 숨깁니다.** 다른 도형으로 재연결하거나 바닥에 떨어뜨리지 않습니다.
- 숨겨진 도형은 그리기·바닥 경계 계산에서 제외됩니다. 숨겨진 대상만 있는 기능 키는 실행하지 않습니다.

부속에 독립 동작을 추가할 수 있습니다.

```cpp
scene.AddRotation(Id(60), GLFW_KEY_U, {0,1,0}, Shape::bottom,
    1, 90, 180, Mode::Once, TransformSpace::Local);
scene.AddScale(Id(60), GLFW_KEY_I, {0,1,0}, Shape::bottom,
    .5f, 1.5f, .4f, Mode::PingPong);
scene.AddMovement(Id(60), GLFW_KEY_J, {1,0,0}, .2f, .1f, Mode::PingPong);
```

위 세 동작은 같은 부속에서 동시에 사용할 수 있습니다. `bottom`을 연결·회전·신축 기준으로 같이 쓰면 길이 변화와 회전 중 밑끝이 유지됩니다. 이동 기능은 접점에서 의도적으로 이동시키므로 떨어져 보일 수 있습니다. 기준점이 접점과 다를 때도 회전 중 접점이 이동할 수 있습니다.

## 6. 기능 대상을 자유롭게 선택하기

```cpp
Id(60)        // 도형 하나
Part(WHEELS)  // 파트 전체
Layer(1)      // 1층의 기본 도형 전체
```

예제의 `d`도 특별한 바퀴 전용 키가 아닙니다.

```cpp
scene.AddScale(Layer(1), GLFW_KEY_D, {0,1,0}, Shape::bottom,
    .5f, 1.5f, .6f, Mode::PingPong);
```

`Layer(1)`을 `Layer(2)`나 `Id(BODY_MAIN)`으로 바꾸면 그 대상이 신축합니다. 층 신축은 부속의 크기를 직접 변경하지 않으며, 부속은 접점 이동만 따라갑니다. 각 도형의 초기 크기가 같고 같은 기능을 공유하면 신축 높이가 어긋나지 않습니다.

동일 ID에 신축 기능 두 개 또는 회전 기능 두 개가 겹치면 설정 오류입니다. 파트 기능과 개별 기능의 중복도 포함합니다. 이동은 여러 기능을 합산할 수 있습니다. 부모와 자식에 같은 이동을 각각 부여하면 상속 이동에 자기 이동이 더해집니다.

## 7. 기능 인자와 반복 방식

```cpp
scene.AddScale(대상, 키, 축마스크, 고정점, 최소배율, 최대배율, 초당배율, 모드);
scene.AddRotation(대상, 키, 축, 기준점, 방향, 초당각도, 사이클각도, 모드, 좌표계);
scene.AddMovement(대상, 키, 방향, 사이클거리, 초당거리, 모드, 좌표계);
scene.AddSwap(도형ID1, 도형ID2, 키, 소요초);
```

신축 축마스크 `{0,1,0}`은 로컬 Y만, `{1,1,1}`은 전체 신축입니다. 배율은 초기 크기에 곱하며 `0 < 최소 ≤ 1 ≤ 최대`, `최소 < 최대`여야 합니다. 속도는 양수입니다.

회전 방향은 `+1/-1`입니다. 같은 축에서 둘 다 +1이면 같은 방향, +1/-1이면 반대 방향입니다. 양의 방향은 오른손 법칙을 따릅니다.

| 모드 | 회전·이동 | 신축 | 재입력 |
|---|---|---|---|
| `Once` | 현재에서 한 사이클 | 현재 배율에서 최대까지 | 실행 중 무시 |
| `Loop` | 같은 방향으로 계속 진행 | 최대 도달 후 최소로 돌아가 반복 | 정지·재개 |
| `PingPong` | 지정 각도/거리 사이 왕복 | 최소·최대 사이 왕복 | 정지·재개 |

이동·회전 `Loop`는 사이클 경계에서 되감지 않습니다. 신축 `Once`가 끝난 뒤 다시 눌러도 최대보다 커지지 않습니다.

| 좌표계 | 축의 의미 |
|---|---|
| `TransformSpace::Local` | 생성 각도가 적용된 도형 축 (회전 기본) |
| `TransformSpace::Parent` | 부모 방향을 따르는 축 (이동 기본) |
| `TransformSpace::World` | 고정 월드 축 |

Local 이동은 애니메이션 중 바뀌는 방향이 아니라 초기 자세 기준입니다. 신축 축과 기준점은 항상 로컬 좌표입니다.

### 위치 교환과 바깥쪽 포신 옵션

`AddSwap`은 같은 층과 변환 참조 또는 같은 부모/접점을 가진 두 도형의 설정 위치를 교환합니다. 자식은 함께 움직입니다. 두 대상 중 하나라도 없거나 숨겨져 있으면 실행하지 않습니다.

예제의 `SetOutwardRotation(기능번호,상부ID)`는 기존 19번의 **Y축·180도·Once** 동작을 위한 선택 보정입니다. 임의 각도의 포신이나 같은 방향 회전에는 이 호출을 제거하고 축·방향을 직접 지정합니다. 이 보정은 앞이 -Z이고 좌우가 X축인 기존 탱크 설정을 전제로 합니다.

## 8. 빈 파트와 오류 처리

빈 파트/없는 ID를 대상으로 하는 연결·층 지정·기능은 안전하게 건너뜁니다. 모든 도형이 없어도 빈 화면으로 실행할 수 있습니다. 다만 `scene.Get(없는ID)` 직접 접근, 중복 ID, 순환 연결, 겹친 회전·신축, 음수 크기/속도는 설정 오류입니다.

도형 구성은 실행 전 설정입니다. 런타임에 `scene.shapes.erase()`로 편집하는 인터페이스는 제공하지 않습니다. 생성문을 삭제하고 다시 실행합니다.

바닥 경계와 층 높이는 변환된 바운딩 박스로 계산합니다. 구나 기울어진 도형의 실제 표면보다 범위가 보수적일 수 있습니다. 부품끼리의 충돌이나 물리 시뮬레이션은 하지 않습니다.

이전 `AttachOnTop`은 지정한 지지대만 사용하는 수동 연결 방식으로 남아 있습니다. 지지대 중심 평균 XZ를 사용하는 기존 동작이므로, **빈 층을 자동으로 건너뛰는 새 조립에는 SetLayer를 사용합니다.** `PlaceOnFloor`는 층/부속에 속하지 않는 독립 도형의 초기 바닥 배치용입니다.

## 9. 키와 검증

- 방향키: 조립체 XZ 이동
- `d`: 설정한 층/도형 신축
- `t/g/p/l`: 예제 몸통 회전/포신 회전/깃대 회전/위치 교환
- `x/X`, `z/Z`: 카메라 월드 양/음 방향 이동 (대문자는 Shift)
- `y/Y`, `r/R`: 카메라 자전/원점 공전 토글
- 드래그/휠: 오비트/확대축소
- `o/c/q`: 색상 재추첨/초기화/종료
