# 실습 23 — 걷는 로봇

1200×1200 창, 원근 투영, 깊이 검사와 면 컬링을 사용합니다. 도형과 색상은 별도 GLSL 셰이더에서 처리하며 조명은 사용하지 않습니다.

## 조작

- `w/s/a/d`: 월드 -Z/+Z/-X/+X 방향으로 걷기 시작합니다. 키를 놓아도 계속 걷습니다.
- `+/-`: 이동 속도를 조절합니다. 속도에 따라 팔다리의 흔들림 각도와 주기도 바뀝니다.
- `Space`: 점프합니다. 이동 중에는 이동과 팔다리 흔들기도 계속됩니다. 공중에서 추가 점프는 불가능합니다.
- `o`: 가림막 열기/닫기. 처음에는 닫혀 있습니다.
- `i`: 로봇, 속도, 카메라, 가림막을 초기화하고 장애물 크기와 위치를 다시 추첨합니다. 로봇은 정지 상태로 돌아옵니다.
- `x/X`, `z/Z`: 카메라와 주시점을 월드 X/Z축의 양/음 방향으로 이동합니다. 대문자는 Shift를 함께 누릅니다.
- `y/Y`: 무대 중심의 Y축 주위로 공전합니다. 같은 키를 다시 누르면 정지합니다.
- 좌클릭 드래그: 주시점 중심의 오비트 회전. 버튼을 놓아도 시점은 유지합니다.
- 휠: 확대·축소.
- `q` 또는 Esc: 종료.

## 구현과 설정

설정값은 CPP 상단의 define에서 변경합니다. `ORBIT_ENABLED`는 마우스 오비트의 사용 여부입니다.

방의 여섯 면은 서로 다른 색을 사용합니다. 방을 그릴 때만 앞면을 컬링해 외부 어느 방향에서도 내부가 보이도록 하고, 로봇과 장애물은 일반적인 뒷면 컬링을 사용합니다.

별도 대형 가림막은 사용하지 않습니다. 닫힌 상태에서는 육면체 외부 면이 내부를 가리고, 열 때는 외부 면을 아래에서 위로 걷어 올리듯 제거합니다. 완전히 열리면 내부 면만 보입니다. 초기 상태는 닫힘이며 배경은 흰색입니다.

로봇의 어깨와 엉덩이를 회전축으로 팔다리를 교대로 흔듭니다. 벽 또는 장애물 옆면과 충돌하면 진행 방향을 180도 바꿉니다. 충돌 범위는 `ROBOT_RADIUS`로 보수적으로 설정합니다.

점프는 중력과 가속도 없이 전반부에 등속 상승하고 후반부에 등속 하강합니다. 상승·하강 속도는 `2 * JUMP_HEIGHT / JUMP_SECONDS`로 같습니다. 내려오는 중 장애물 윗면에 도달하면 착지합니다. 장애물 끝을 벗어나면 `DESCEND_SPEED`의 일정한 속도로 내려옵니다.

Visual Studio에서 ComG_1_23을 시작 프로젝트로 설정하고 Debug/x64로 실행합니다.
