# 중간 대비 1 — 그네와 사람

모든 부품은 육면체입니다. 기존 바닥 위에 좌우 ∩자 지지대, 연결 가로봉, 가는 줄 두 개, 좌석과 앉은 사람을 배치합니다. 원근 투영과 깊이 검사·면 컬링을 사용하며 조명은 없습니다.

## 조작

- `s`: 시작/현재 자세에서 정지/재개. 처음에는 정지 상태입니다.
- `o/p`: 흔들림 진폭 감소/증가. 진폭 25도는 -25~+25도를 의미합니다.
- `+/-`: 왕복 속도 증가/감소. 일반 키보드 +/=와 숫자패드 +를 모두 지원합니다.
- `x/X`, `z/Z`: 카메라와 주시점을 월드 X/Z축 양/음 방향으로 이동합니다. 대문자는 Shift와 함께 누릅니다.
- `y/Y`: 고정된 그네 중심의 Y축 주위를 양방향 공전합니다. 같은 키를 다시 누르면 정지합니다.
- 좌클릭 드래그: 주시점 중심 오비트. 버튼을 놓아도 시점은 유지합니다.
- 휠: 확대/축소.
- `c`: 그네 설정·자세·카메라 초기화.
- `q` 또는 Esc: 종료.

## 설정 변경

CPP 상단의 define으로 수정합니다.

- `SWING_START_ANGLE`: 처음 정지한 자세의 각도. 기본 0도.
- `SWING_INITIAL_AMPLITUDE`: 초기 진폭. 기본 25도.
- `SWING_MIN_AMPLITUDE`, `SWING_MAX_AMPLITUDE`: 진폭 조절 범위. 기본 5~45도.
- `SWING_AMPLITUDE_STEP`: 키 한 번당 진폭 변화량. 기본 5도.
- `SWING_INITIAL_SPEED`, `SWING_MIN_SPEED`, `SWING_MAX_SPEED`: 초기 위상 속도와 범위. 기본 60, 15, 150도/초.
- `SWING_SPEED_STEP`: 속도 변경량. 기본 15도/초.
- `KEY_SWING`, `KEY_ANGLE_DOWN/UP`, `KEY_SPEED_DOWN/UP`: 조작키.
- `PERSON_ENABLED`: 사람 표시 0=숨김, 1=표시. 기본 1. 그네와 애니메이션은 유지됩니다.
- `ORBIT_ENABLED`: 마우스 오비트 0=끔, 1=켬. 기본 1. 키보드 공전과 휠은 별개입니다.
- 나머지 크기 define: 지지대, 줄, 좌석, 사람의 각 부품 전체 크기.

위상 속도 60도/초이면 한 왕복에 360/60=6초가 걸립니다. 실제 그네 각도는 `진폭 * sin(위상)`이므로 중앙에서는 빠르고 양 끝에서는 부드럽게 방향을 바꿉니다. 진폭 변경도 조금씩 적용합니다. 정지 중 설정을 바꾸면 자세는 고정하고 재개 시 반영합니다.

변환행렬은 `가로봉 회전축 → 줄/좌석 → 사람` 순서로 연결합니다. 좌석 윗면에 몸통 하부가 고정되어 사람 전체가 그네와 함께 움직입니다. 팔·다리는 서로 구별되도록 벌려 놓고 독립 애니메이션은 적용하지 않습니다.

Visual Studio에서 ComG_mid_test1을 시작 프로젝트로 설정하고 Debug/x64로 실행합니다. 셰이더는 프로젝트의 vertex.glsl과 fragment.glsl을 그대로 사용합니다.
