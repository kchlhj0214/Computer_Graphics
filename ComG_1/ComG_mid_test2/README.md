# 중간 대비 2 — 육면체 조립과 변환

일반적인 사용에서는 CPP의 **수정 영역 ①**과 **수정 영역 ②**만 수정합니다. 실제 구현은 CPP 하나에 있으며 셰이더는 vertex.glsl과 fragment.glsl입니다.

## ① 객체 설정

번호는 0~39입니다. 각 행은 다음 순서입니다.

```cpp
{활성화, {X크기,Y크기,Z크기}, {중심X,중심Y,중심Z}, {R,G,B}, {초기X각,초기Y각,초기Z각}}
```

예: 0번 행을 다음으로 바꾸면 바닥에 놓인 육면체가 생성됩니다.

```cpp
{true, {.4f,.6f,.4f}, {0,.3f,0}, {.9f,.2f,.2f}, {0,0,0}}, // 0번
```

20~30번은 비활성 예비 객체이며, 31~39번은 사람 샘플입니다. 기존 0~19번 설정은 유지됩니다. 크기는 양수, 색상은 0~1 범위로 입력합니다. 초기 회전은 X, Y, Z 순으로 적용됩니다. 객체의 중심/크기를 변경하면 변환 기준점과 방향키 경계도 그 값을 따릅니다.

## 랜덤 색상

색상 인자에 다음 중 하나를 넣습니다.

```cpp
{true, {.3f,.3f,.3f}, {0,.15f,0}, Color::Random(), {0,0,0}}, // 개별 랜덤
{true, {.3f,.3f,.3f}, {1,.15f,0}, Color::Random(1), {0,0,0}}, // 1번 색상 그룹
{true, {.3f,.3f,.3f}, {2,.15f,0}, Color::Random(1), {0,0,0}}, // 위와 동일한 색
```

인자 없는 Random()은 각각 추첨합니다. Random(0), Random(1)처럼 0 이상의 같은 그룹 번호를 사용하면 동일한 색을 공유합니다. 객체 번호와 색상 그룹 번호는 별개입니다. 고정 색상은 기존 `{R,G,B}` 또는 `Color::Fixed(R,G,B)`로 지정합니다.

리셋 `r`을 누르면 모든 랜덤 색을 다시 추첨하며, 같은 그룹끼리는 새 색도 공유합니다. 고정 색은 유지됩니다. RGB 추첨 범위는 `RANDOM_COLOR_MIN/MAX`로 조절하며 기본 0.10~0.90입니다.

## ② 키 명령

```cpp
case GLFW_KEY_A:
    Run(Move(0,{1,0,0}));
    break;
```

- `Move(번호,{dx,dy,dz})`: 해당 단계 시작 위치에서 상대 이동.
- `Rotate(번호,Axis::Y,90,Pivot::Center)`: 조립 공간의 Y축으로 90도 회전.
- `Scale(번호,Axis::Y,+.5f,Pivot::Bottom)`: 아래쪽 기준점을 고정하고 Y방향 1.5배 신축.
- 회전/신축 기준점 생략 시 자기 중심입니다.
- `Axis::X/Y/Z`를 사용합니다. 회전 후에도 축은 조립 공간의 고정 축입니다.
- 기준점은 `Pivot::Center/Left/Right/Bottom/Top/Front/Back` 또는 `Point(x,y,z)`입니다.
- Point는 방향키로 전체를 움직이면 함께 이동합니다. 회전·신축 명령 시작 시 기준점을 기록합니다.
- 회전각은 -360~360도입니다. 신축 변화량 -0.5는 0.5배, +0.5는 1.5배입니다. -1 이하는 거부합니다.

## 동시·순차 실행

```cpp
Run(Parallel({Move(0,{1,0,0}),Move(1,{1,0,0})}));
Run(Sequence({Move(0,{1,0,0}),Rotate(0,Axis::Y,90),Scale(0,Axis::Y,.5f)}));
```

Parallel은 전부 끝나야 완료되고, Sequence는 앞 명령이 끝나야 다음 단계가 시작됩니다. 이동은 `MOVE_SPEED` 거리/초, 회전은 `ROTATE_SPEED` 도/초, 신축은 `SCALE_SPEED` 배율 변화량/초를 사용하므로 명령별 완료 시간이 다를 수 있습니다.

같은 객체의 여러 변환을 동시에 진행하려면 하나의 Parallel에 넣습니다. 고정 시간 간격마다 기재한 순서로 변환을 합성합니다. 각 명령은 자기 기준점을 시작 시 기록하므로, 부모를 지정한 객체의 기준점은 부모와 함께 움직입니다. 같은 객체 자체의 다른 이동을 면 기준점이 자동 추적하는 것은 아닙니다. 별도 작업 두 개가 같은 객체를 동시에 제어하려 하면 콘솔에 오류를 표시합니다.

하나의 조립물처럼 회전하려면 각 객체에 같은 축·각도·Point를 전달합니다. 각자 Center를 사용하면 각 객체가 자기 중심에서 회전합니다.

## 반복·왕복·정지/재개

```cpp
Run(Repeat(Move(0,{.2f,0,0}),3));  // 총 .6 이동
Run(Repeat(PingPong(Move(0,{1,0,0})),3)); // 갔다 돌아오기를 3번
slots[0]=Run(Repeat(PingPong(Rotate(0,Axis::Y,90)),Forever));
TogglePause(slots[0]);
Pause(slots[0]);
Resume(slots[0]);
Cancel(slots[0]); // 모습은 유지하고 실행만 취소
```

PingPong에는 단일 Move/Rotate/Scale을 넣습니다. 여러 객체를 함께 왕복시키려면 Parallel 안에 각각 PingPong을 넣습니다. Repeat는 Parallel/Sequence에도 적용할 수 있습니다. 왕복 신축은 역배율을 적용하여 원래 크기로 돌아옵니다.

같은 키로 최초 시작과 정지·재개를 처리하려면:

```cpp
if(IsFinished(slots[0]))
    slots[0]=Run(Repeat(PingPong(Move(0,{1,0,0})),Forever));
else
    TogglePause(slots[0]);
```

무한반복은 완료되지 않으므로 Sequence 중간에 넣으면 뒤 명령은 실행되지 않습니다. 반복은 현재 상태에 누적됩니다. 무한 신축처럼 계속 크기가 커지거나 작아지는 설정에는 주의합니다.

## 기본 명령과 설정

- 방향키: 모든 활성 객체를 하나처럼 월드 XZ 방향으로 이동. 변환된 8개 꼭짓점 기준으로 바닥 범위를 제한합니다.
- 명령 Move/Rotate/Scale에는 바닥 경계가 없습니다. 이미 밖에 있으면 방향키의 더 바깥쪽 이동은 막고 안쪽 이동은 허용합니다.
- `x/X`: 카메라 기준 오른쪽/왼쪽. `z/Z`: 카메라 기준 뒤쪽/앞쪽. 카메라가 기울면 전후 이동의 Y좌표도 바뀝니다.
- `y/Y`: 월드 원점 Y축 기준 공전 시작/정지.
- 마우스 드래그/휠: 오비트/확대축소.
- `r`: 객체, 작업, 전체 위치, 카메라 초기화. `q`: 종료.
- `FLOOR_ENABLED`: 0=바닥 숨김, 1=표시. 방향키 경계는 유지됩니다.
- `BACKGROUND_RED/GREEN/BLUE`: 기본 흰색. 바탕색을 바꾸는 위치입니다.

Visual Studio에서 ComG_mid_test2를 시작 프로젝트로 지정하고 Debug/x64로 빌드·실행합니다.

## 표시 방식 토글

- `w`: 객체 솔리드/와이어 전환. 바닥은 솔리드를 유지합니다. 와이어는 삼각형 메시의 선을 표시하므로 면의 대각선도 보입니다.
- `t`: 원근/직교 투영 전환. 직교 범위는 카메라 거리와 시야각으로 계산하므로 휠 확대·축소도 유지됩니다.
- `e`: 깊이 검사와 뒷면 컬링을 함께 켜거나 끕니다. 끄면 그리는 순서대로 표시되어 가려진 면도 덮어 그려질 수 있습니다.

초기값은 솔리드·원근·은면 제거 켜짐이며, `r`로 초기화됩니다. `WIREFRAME_INITIAL`, `PERSPECTIVE_INITIAL`, `HIDDEN_SURFACE_INITIAL`로 기본값을 변경할 수 있습니다.

## 선택적 부모 상속

설정 행의 마지막에 `부모 번호, 신축 상속`을 추가할 수 있습니다. 생략 시 `-1, false`로 기존 동작을 유지합니다.

```cpp
{true, {.3f,.5f,.2f}, {0,.7f,0}, Color::Random(), {0,0,0}, -1, false}, // 0: 몸통
{true, {.1f,.4f,.1f}, {-.23f,0,0}, Color::Random(), {0,0,0}, 0, false}, // 1: 팔
```

부모가 있는 객체의 중심 위치, Move 방향/거리, Rotate/Scale 축, Point 좌표는 부모 중심 기준입니다. 부모의 초기 크기를 상대 좌표에 곱하지 않으므로 위치 단위는 기존과 같습니다. 부모 없는 객체는 기존 조립 공간 기준 그대로입니다.

`inheritScale=false`이면 자식의 크기는 유지하면서 부모 신축에 따라 연결 위치만 이동합니다. `true`이면 크기와 위치 모두 부모 신축을 따릅니다. false에서 부모가 비균등 신축과 회전으로 비스듬히 변형되면 축을 직교화해 회전만 전달합니다. 부모가 비활성화되면 모든 후손도 숨깁니다. 순환 연결과 잘못된 부모 번호는 거부합니다.

```cpp
Run(Repeat(PingPong(Rotate(1,Axis::X,30,Pivot::Top,1.0f)),Forever));
Run(Rotate(0,Axis::Y,90,Pivot::Center,2.0f));
```

팔을 흔드는 중 몸통을 회전해도 팔의 어깨 위치와 회전축이 몸통을 따라갑니다. 자식 동작은 부모에 영향을 주지 않습니다. 전체 이동/회전은 부모에만 지정하세요. 부모와 자식에게 중복 명령을 주면 상속과 자체 변환이 모두 적용됩니다.

Swap은 부모 번호와 신축 상속 설정이 같은 두 객체 사이에서 사용할 수 있습니다. 기존의 부모 없는 객체 사이 Swap은 그대로 동작합니다. 방향키 경계 계산과 그리기는 최종 상속된 위치를 사용합니다.

## 사람 샘플 — 31~39번

31 몸통 → 32 왼팔, 33 오른팔, 34 왼다리, 35 오른다리, 36 머리.
36 머리 → 37 코, 38 왼눈, 39 오른눈.

위 객체들은 설정 영역 ①에서 크기·색상·부모 기준 위치를 변경합니다. 31번을 비활성화하면 사람 전체가 숨고 이동 계산도 중단됩니다. 걷기에는 별도 animation 행렬을 사용하므로 기존 변환 명령의 model을 덮어쓰지 않습니다.

- `v`: 앞(-Z), `b`: 뒤(+Z), `n`: 왼쪽(-X), `m`: 오른쪽(+X). 한 번 누르면 계속 걷습니다.
- `Space`: 등속 상승·하강 점프. 이동 중 점프와 공중 팔다리 흔들기를 지원합니다.
- 다른 활성 육면체는 장애물입니다. 옆면 또는 바닥 경계에 닿으면 반대로 돌아갑니다.
- 점프 중 장애물 윗면에 착지할 수 있고, 끝을 지나면 일정 속도로 내려옵니다.
- `r`: 초기 위치·정지 상태로 복원합니다.

`PLAYER_SPEED`, `PLAYER_WALK_ANGLE`, `PLAYER_PHASE_SPEED`, `PLAYER_JUMP_HEIGHT/SECONDS`, `PLAYER_DESCEND_SPEED`로 동작을 조절합니다. 기존 방향키는 사람까지 포함한 전체 조립물을 이동시킵니다. 충돌은 변환된 육면체 AABB와 사람의 보수적인 수평 범위를 사용합니다.
