# 중간 대비 2 — 육면체 조립과 변환

일반적인 사용에서는 CPP의 **수정 영역 ①**과 **수정 영역 ②**만 수정합니다. 실제 구현은 CPP 하나에 있으며 셰이더는 vertex.glsl과 fragment.glsl입니다.

## ① 객체 설정

번호는 0~19입니다. 각 행은 다음 순서입니다.

```cpp
{활성화, {X크기,Y크기,Z크기}, {중심X,중심Y,중심Z}, {R,G,B}, {초기X각,초기Y각,초기Z각}}
```

예: 0번 행을 다음으로 바꾸면 바닥에 놓인 육면체가 생성됩니다.

```cpp
{true, {.4f,.6f,.4f}, {0,.3f,0}, {.9f,.2f,.2f}, {0,0,0}}, // 0번
```

모든 객체는 기본 false입니다. 크기는 양수, 색상은 0~1 범위로 입력합니다. 초기 회전은 X, Y, Z 순으로 적용됩니다. 객체의 중심/크기를 변경하면 변환 기준점과 방향키 경계도 그 값을 따릅니다.

## ② 키 명령

```cpp
case GLFW_KEY_A:
    Run(Move(0,{1,0,0}));
    break;
```

- `Move(번호,{dx,dy,dz})`: 해당 단계 시작 위치에서 상대 이동.
- `Rotate(번호,Axis::Y,90,Pivot::Center)`: 조립 공간의 Y축으로 90도 회전.
- `Scale(번호,Axis::Y,+.5f,Pivot::Bottom)`: 아래쪽 기준점을 고정하고 Y방향 1.5배 신축.
- 회전/신축 기준점 생략 시 자기 중심입니다.
- `Axis::X/Y/Z`를 사용합니다. 회전 후에도 축은 조립 공간의 고정 축입니다.
- 기준점은 `Pivot::Center/Left/Right/Bottom/Top/Front/Back` 또는 `Point(x,y,z)`입니다.
- Point는 방향키로 전체를 움직이면 함께 이동합니다. 회전·신축 명령 시작 시 기준점을 기록합니다.
- 회전각은 -360~360도입니다. 신축 변화량 -0.5는 0.5배, +0.5는 1.5배입니다. -1 이하는 거부합니다.

## 동시·순차 실행

```cpp
Run(Parallel({Move(0,{1,0,0}),Move(1,{1,0,0})}));
Run(Sequence({Move(0,{1,0,0}),Rotate(0,Axis::Y,90),Scale(0,Axis::Y,.5f)}));
```

Parallel은 전부 끝나야 완료되고, Sequence는 앞 명령이 끝나야 다음 단계가 시작됩니다. 이동은 `MOVE_SPEED` 거리/초, 회전은 `ROTATE_SPEED` 도/초, 신축은 `SCALE_SPEED` 배율 변화량/초를 사용하므로 명령별 완료 시간이 다를 수 있습니다.

같은 객체의 여러 변환을 동시에 진행하려면 하나의 Parallel에 넣습니다. 고정 시간 간격마다 기재한 순서로 변환을 합성합니다. 각 명령은 자기 기준점을 시작 시 기록하므로, 이동하는 중심을 추적하는 부모·자식 기능은 없습니다. 별도 작업 두 개가 같은 객체를 동시에 제어하려 하면 콘솔에 오류를 표시합니다.

하나의 조립물처럼 회전하려면 각 객체에 같은 축·각도·Point를 전달합니다. 각자 Center를 사용하면 각 객체가 자기 중심에서 회전합니다.

## 반복·왕복·정지/재개

```cpp
Run(Repeat(Move(0,{.2f,0,0}),3));  // 총 .6 이동
Run(Repeat(PingPong(Move(0,{1,0,0})),3)); // 갔다 돌아오기를 3번
slots[0]=Run(Repeat(PingPong(Rotate(0,Axis::Y,90)),Forever));
TogglePause(slots[0]);
Pause(slots[0]);
Resume(slots[0]);
Cancel(slots[0]); // 모습은 유지하고 실행만 취소
```

PingPong에는 단일 Move/Rotate/Scale을 넣습니다. 여러 객체를 함께 왕복시키려면 Parallel 안에 각각 PingPong을 넣습니다. Repeat는 Parallel/Sequence에도 적용할 수 있습니다. 왕복 신축은 역배율을 적용하여 원래 크기로 돌아옵니다.

같은 키로 최초 시작과 정지·재개를 처리하려면:

```cpp
if(IsFinished(slots[0]))
    slots[0]=Run(Repeat(PingPong(Move(0,{1,0,0})),Forever));
else
    TogglePause(slots[0]);
```

무한반복은 완료되지 않으므로 Sequence 중간에 넣으면 뒤 명령은 실행되지 않습니다. 반복은 현재 상태에 누적됩니다. 무한 신축처럼 계속 크기가 커지거나 작아지는 설정에는 주의합니다.

## 기본 명령과 설정

- 방향키: 모든 활성 객체를 하나처럼 월드 XZ 방향으로 이동. 변환된 8개 꼭짓점 기준으로 바닥 범위를 제한합니다.
- 명령 Move/Rotate/Scale에는 바닥 경계가 없습니다. 이미 밖에 있으면 방향키의 더 바깥쪽 이동은 막고 안쪽 이동은 허용합니다.
- `x/X`: 카메라 기준 오른쪽/왼쪽. `z/Z`: 카메라 기준 뒤쪽/앞쪽. 카메라가 기울면 전후 이동의 Y좌표도 바뀝니다.
- `y/Y`: 월드 원점 Y축 기준 공전 시작/정지.
- 마우스 드래그/휠: 오비트/확대축소.
- `r`: 객체, 작업, 전체 위치, 카메라 초기화. `q`: 종료.
- `FLOOR_ENABLED`: 0=바닥 숨김, 1=표시. 방향키 경계는 유지됩니다.
- `BACKGROUND_RED/GREEN/BLUE`: 기본 흰색. 바탕색을 바꾸는 위치입니다.

Visual Studio에서 ComG_mid_test2를 시작 프로젝트로 지정하고 Debug/x64로 빌드·실행합니다.
