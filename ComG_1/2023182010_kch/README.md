# 2023182010_kch — 저울형 크레인

ComG_mid_test2의 C++20 프로젝트 설정, 육면체·상속·변환 명령 구조와 셰이더를 복사해 만든 프로젝트입니다. 원본 프로젝트는 수정하지 않았습니다. ComG_1.slnx에 새 프로젝트를 등록했습니다.

GLFW의 OpenGL 3.3 core profile을 사용합니다. 기본 창은 1200×1200이며, 원근 투영·깊이 검사·뒷면 컬링을 적용합니다.

## 키 명령

| 키 | 동작 |
|---|---|
| 1 / 2 | 팔1 왕복 시작 / 정지 후 아래 수직으로 복귀 |
| 3 / 4 | 팔2 왕복 시작 / 정지 후 아래 수직으로 복귀 |
| 5 / 6 누르고 있기 | 중앙 기둥의 Y축 양/음 방향 회전 |
| l / r | 왼쪽 / 오른쪽 선택. 선택한 손은 노란색 |
| → / ← | 선택한 팔과 손을 안쪽 / 바깥쪽으로 한 단계 이동 |
| + / - | 카메라를 월드 Z축 양/음 방향으로 이동 |
| o | 화면 중심 Y축 기준 카메라 공전 시작/정지 |
| s | 전체 초기화 |
| q 또는 Esc | 종료 |

기존 마우스 드래그 오비트, 휠 확대축소, w/t/e의 와이어·투영·은면 제거 토글도 유지합니다. 원래 코드의 방향키 전체 이동과 r 리셋 등은 위 과제 명령으로 교체했습니다.

## 구현

- 객체 0은 받침, 1은 중앙 기둥, 2는 위 몸체, 3/4는 팔, 5/6은 손입니다. 남은 객체는 비활성 예비 칸입니다.
- 중앙 기둥 → 위 몸체 → 팔 → 손의 부모 연결을 사용합니다.
- 팔은 위 몸체 연결점을 기준으로 X축 -60~+60도 사이를 사인 함수로 왕복합니다. 정지 명령은 수직 자세로 복귀합니다.
- 손은 팔 끝을 따라가면서 앞뒤 회전과 바깥쪽 벌어짐을 역회전으로 상쇄합니다. 항상 XZ 평면과 평행합니다.
- 팔 위치는 각각 0~5단계입니다. →는 안쪽, ←는 바깥쪽으로 원래 위치까지 이동합니다. 선택한 쪽을 안쪽으로 옮기면 그쪽이 올라가고 반대쪽은 내려갑니다.
- 5/6을 누르는 동안 두 팔이 바깥쪽으로 벌어지고 키를 놓으면 원래 위치로 돌아옵니다. 중앙 회전은 키를 놓으면 멈춥니다.
- 동작 범위·단계·속도는 CPP 상단 CRANE_* define, 부품 크기와 색상은 boxSettings에서 조절합니다.

Visual Studio에서 2023182010_kch를 시작 프로젝트로 설정하고 Debug/x64로 실행합니다. 셰이더 작업 경로는 프로젝트 폴더입니다.
