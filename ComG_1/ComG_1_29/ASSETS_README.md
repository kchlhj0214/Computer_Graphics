# 눈 결정과 태양계 OBJ 에셋

- snowflake.obj: 여섯 갈래의 입체 눈 결정. 높이 1, 폭 약 0.866, 두께 약 0.219. 중심 원점.
- earth.obj: 지구, 대륙과 바다를 표현한 컬러 표면.
- mercury.obj: 수성, 회색 크레이터 표면.
- venus.obj: 금성, 구름으로 덮인 대기 표면.
- sun.obj: 태양, 주황색 표면과 발광 재질 정보.

각 OBJ 옆의 같은 이름 MTL과 textures 폴더를 함께 보관하세요. OBJ는 삼각형 면과 UV(vt), 법선(vn)을 포함합니다. 천체는 중심 (0,0,0), 반지름 1, Y축이 북극이며 실제 천체 간 크기 비율은 적용하지 않았습니다. 천체당 9,024개 삼각형입니다.

## 불러오기

OBJ 로더는 f의 v/vt/vn 인덱스, mtllib, usemtl을 지원해야 합니다. 컬러 표면은 MTL의 map_Kd 이미지를 UV 좌표로 샘플링해야 표시됩니다. 현재 프로젝트의 fragment.glsl은 단색 uColor 방식이므로, OBJ를 추가하는 것만으로 표면 이미지가 표시되지는 않습니다. 텍스처 지원은 렌더링 코드에서 별도로 연결해야 합니다. 태양은 MTL의 Ke/map_Ke 또는 조명을 받지 않는 셰이더를 사용하세요.

OBJ에는 애니메이션이 저장되지 않습니다. 눈이 내리려면 snowflake.obj를 여러 번 배치해 매 프레임 Y좌표를 줄이고, 화면 아래로 내려간 결정은 위쪽에서 재배치하세요. 작은 크기로 축소하고 회전과 낙하 속도를 조금씩 다르게 설정하면 자연스럽습니다.
